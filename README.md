# my-setup
Simple scripts to setup development environments

## Quick Setup

To setup your macOS development environment, you can run this command:

```bash
/bin/zsh -c "$(curl -fsSL https://raw.githubusercontent.com/nennogabriel/my-setup/main/OS/macos_amd64/setup.sh)"
```

This will:
1. Download and execute the setup script
2. Install Homebrew if it's not already installed
